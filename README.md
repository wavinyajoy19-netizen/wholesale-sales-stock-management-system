# Wholesale Sales and Stock Management System

## Project Overview

The Wholesale Sales and Stock Management System is a web-based application developed to help wholesale businesses manage their daily operations. The system simplifies sales recording, stock management, supplier management, purchasing, customer records, expenses, and financial reporting.

The project was developed using PHP, MySQL, HTML, CSS, JavaScript, and XAMPP.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap (where applicable)
- XAMPP
- Git and GitHub

## Main System Features

- User login and authentication
- Role-based access control
- Dashboard with business summaries
- Product and stock management
- Sales recording and receipt generation
- Cash and M-Pesa payment recording
- Customer management
- Supplier management
- Purchase orders and delivery receiving
- Stock movement tracking
- Expense management
- Supplier payment management
- Sales and financial reports
- Activity logs

## User Roles

The system supports different user roles:

1. **Admin** – Manages users and oversees system operations.
2. **Accountant** – Handles financial records, expenses, and reports.
3. **Cashier** – Records customer sales and payments.
4. **Storekeeper** – Manages stock and deliveries.

## Installation and Setup

1. Install XAMPP on your computer.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin in your browser.
5. Create a MySQL database named `wholesale_db`.
6. Import the project's database SQL file if included in the repository.
7. Configure your local database connection in `includes/db.php`.
8. Open the project in your browser:

   `http://localhost/wholesale_system/`

**Note:** Database credentials should be configured locally and should not be uploaded to GitHub.
